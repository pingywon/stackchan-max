M-M-Meet MAX.

A palm-sized desk robot with a face you can swap and a brain you choose. Custom firmware for the M5Stack StackChan.

Change its face

What it can do

  • Wear a new face

    MAX, VOLT or the stock face. Switch from the panel or the robot.

  • Talk through any AI

    Claude, ChatGPT or a free one. Change it on a web page.

  • Play characters

    Up to 8, each with a personality, a voice and a face.

  • Answer to 11 names

    Jarvis, Computer, Hi Stack Chan and eight more.

  • Move when you ask

    It turns its head, changes its lights and plays gestures.

  • Look where it is going

    The eyes lead the head into every turn.

  • Do small jobs

    Weather, reminders, pausing a Pi-hole.

  • Remember you

    Write notes once. It knows them in every chat.

  • Keep time

    A clock, a weather display or a stock ticker on your desk.

Pick the AI

The robot is a microphone, a speaker and a face. The thinking happens on your computer, so you choose who does it.

Free

Yours
Any model on Ollama

Paste a key, tap who answers. It applies on the next thing you say. Keys never go to the robot.

Built with Claude

I built this with Claude Code, Anthropic's coding assistant. Claude wrote the code. I steered and tested it on the real robot.

  1. I say what I want

    "Give it a Max Headroom face."

  2. Claude writes it

    After reading M5Stack's source first.

  3. Claude checks itself

    A simulator, a mock panel and a fake robot.

  4. I flash the robot

    By USB, then paste the boot log back.

  5. We fix the surprises

    Real hardware always has some.

One catch shaped it all. Claude's computer has no USB port. It can compile and simulate, but never flash. So the repo ships a simulator, a mock server and a self-test.

Make it yours the same way. Open the repo in Claude Code, or any coding assistant, and start it at docs/STATUS.md.

Try it without a robot

No hardware and no API key. Clone the repo, then run either one.

Click around the control panel

git clone {{REPO_URL}}.git
cd {{REPO_NAME}}
python3 workshop/portal/mock_server.py --port 8130

Then open http://localhost:8130/

Watch a fake robot hold a conversation

cd server/bridge
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
python selftest.py

Needs the system libopus. Ends with "all checks passed".

Have the kit? Build and flash it. There is no prebuilt download.
